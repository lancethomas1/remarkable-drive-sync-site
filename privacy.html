Privacy policy

Last updated: 23 November 2026

remarkable-drive-sync is a personal tool used only by its owner. This page describes what it does with Google user data.

What it accesses

The tool asks for one Google permission, drive.file. With it, the tool can create files and folders in the owner's Google Drive and can read and update only those files and folders it created. It cannot see any other Drive content, and it requests no other Google data.

What it does with that access

It uploads PDF copies of the owner's reMarkable notebooks to a folder it creates in the owner's Google Drive, and updates those PDFs when the notebooks change. It also keeps two small status files in that folder.

Storage and sharing

The tool has no server and no database. Nothing is collected, stored elsewhere, sold, or shared with anyone. Files stay in the owner's own Google Drive. Google user data is not used for advertising or to train any model.

Removing access

Access can be withdrawn at any time at myaccount.google.com/permissions. Files already uploaded stay in Google Drive until the owner deletes them.

Contact

Questions can be raised through the GitHub account that hosts this page.
