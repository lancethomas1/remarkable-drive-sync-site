remarkable-drive-sync

remarkable-drive-sync is a personal tool that copies handwritten notebooks from its owner's reMarkable tablet into the owner's own Google Drive as PDF files.

It is not a public service. It is used by one person, with their own accounts, and is not offered to anyone else.

The tool uses Google's drive.file permission, which only lets it see and change the files and folders it created itself. It cannot read anything else in Google Drive.
